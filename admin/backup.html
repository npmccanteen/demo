📤 Restore from Backup

Backup file থেকে data restore কর। ⚠️ এটা dangerous — সাবধানে use কর।

⚠️ সতর্কতা:
• Restore করলে existing data-এর উপর overwrite হতে পারে
• আগে current data-এর একটা backup নিয়ে রাখ
• শুধু emergency-তে use কর (accidental delete, corruption)
