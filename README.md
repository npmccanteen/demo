# Meal System

Hostel canteen management with OCR-based student import and OMR meal detection.

## Setup

1. Firebase project: `canteenappnpmc`
2. Enable Firestore (test mode)
3. GitHub Pages: Settings → Pages → main branch / root

## Files

- `index.html` — Landing
- `student-import.html` — OCR import
- `firebase-config.js` — Firebase keys
- `js/firebase-init.js` — SDK init
